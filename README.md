# Task 1 – Responsive Landing Page

A modern and responsive landing page developed as part of my internship Task 1 using HTML, CSS, and JavaScript.

## 🚀 Project Overview

This project demonstrates the development of a responsive landing page with an interactive navigation bar. The website is designed to provide a smooth user experience across desktop, tablet, and mobile devices.

The main focus of this project is implementing a fixed navigation bar with hover effects and a dynamic style change when the user scrolls.

## ✨ Features

- 📌 Fixed navigation bar
- 🎨 Navigation hover effects
- 📜 Navbar style changes on scrolling
- 🔗 Smooth scrolling between sections
- 📱 Fully responsive design
- 🍔 Responsive mobile hamburger menu
- 🔄 Active navigation indicator
- 💬 Interactive contact form
- 💻 Desktop, tablet, and mobile support
- ⚡ Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
